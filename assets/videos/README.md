## 部署注意

- 视频随仓库推到 Vercel / Netlify / GitHub Pages 即可
- 建议加 `Cache-Control: public, max-age=31536000`（Vercel 默认就是 immutable）
- 移动端播放：`playsinline muted` 已配置
- 若以后视频变大，可改成 B 站 / YouTube unlisted 嵌入
